# Research COPS website

A static site deployed on Vercel. The marketing pages are generated by a small Node script with no dependencies, so every page shares one header and footer.

## What's where

```
build/build.js        shared header/footer, page templates, vercel.json + sitemap generation
build/content.js      copy for managed services, the automation add-on, and audiences
build/platform.js     Research Centric OPS copy: modules, methodologies, plans, compare tables
build/contact.html    quote/demo form (reused on many pages)
src/home.html         homepage body
src/legacy/           original <main> markup for insights.html and policy.html
assets/               site.css, pages.css, platform.css, chrome.css, site.js, rc-data.js, genie.js
docs/                 redesign plan + drafted articles to publish through admin
```

Generated output (do not edit by hand): `index.html`, `404.html`, `platform/`, `pricing/`, `solutions/`, `who-we-serve/`, `about/`, `contact/`, `insights.html`, `policy.html`, `solution.html` (redirect), `vercel.json`, `sitemap.xml`, `robots.txt`.

Never touched by the build: `admin.html`, `admin.js`, the Firebase config, `workflow-hub.html` (apart from the one-off rebrand), `workflow-hub-app.js`, `insights.js`, `policy.js`, `theme.js` and `cookie-consent.js`.

## Edit and rebuild

```bash
node build/build.js
```

## Preview locally

```bash
npx http-server . -p 5190 -c-1
```

## Data flow (unchanged from before)

- The quote form and Support Genie write to the Firestore `leads` collection, with the same fields as before. Leads appear in admin.
- The footer contact details and the Calendly link come from `settings/footer`, which is edited in admin.
- Homepage "Insights" cards show the latest 3 posts from the `blogs` collection.
- `insights.html` (blogs, news, polls) and `policy.html` (privacy, terms, cookies) still run on `insights.js` and `policy.js`.

## Before launch

- Remove the admin fallback password from public JS (`admin.js:433`).
- Review the Firestore security rules.
- Point the "Sign in" link at the platform URL.
- Add the panel book PDF.
